# Live AI assistant setup

The Islamic assistant works in two modes:

- **Live (Claude)** — answers are generated by Anthropic's API through this
  project's server. Requires an API key and a signed-in account.
- **Offline** — the bundled knowledge base in `src/ai/islamicKnowledge.js`,
  plus Quran translation search. Works with no key, no network, and no account.

The app shows which mode is active in **AI Assistant** and **Settings**. It
never ships an API key: the key belongs to the server only.

## 1. Add the key

From the project root:

```bash
npm run ai:configure
```

Paste the key at the hidden prompt. Create one at
https://console.anthropic.com/. It starts with `sk-ant-`.

The script:

- writes `ANTHROPIC_API_KEY` to the root `.env` (already gitignored),
- accepts pasted input without echoing it,
- refuses an existing key unless you pass `--replace`,
- never prints the key, only its last four characters,
- sets restrictive file permissions where the OS supports them.

You can also edit `.env` by hand — the file already has an
`ANTHROPIC_API_KEY=` line. Do **not** rename it to `EXPO_PUBLIC_ANTHROPIC_API_KEY`
or put it anywhere in `src/`: `EXPO_PUBLIC_*` values are compiled into the
shipped app and anyone could spend the key.

## 2. Restart the API

The server reads `.env` at startup:

```bash
npm run server        # or stop and restart npm run dev
```

Do not run `start.bat`: it force-kills every `node.exe` on the machine.

Optional overrides in `.env`:

```ini
# ANTHROPIC_MODEL=claude-sonnet-5
# ANTHROPIC_MAX_TOKENS=700
```

## 3. Verify

```bash
npm run ai:status
```

Expected once the server has restarted with the key:

```
Key:    looks valid (…abcd)
Server: live assistant ON (model: claude-sonnet-5)
```

From the app, sign in (the `/api/ai/chat` route requires authentication),
open **AI Assistant**, and the header should show the live badge instead of
"Offline mode". Ask a question; answers then carry the live source label.

## Troubleshooting

| Symptom | Cause / fix |
| --- | --- |
| `Server: live assistant OFF` after saving | The API process is still running with the old environment. Restart it. |
| `server not reachable` | Start the API on port 3001 (`npm run server`). |
| Header stays "Offline mode" | Check `/api/ai/status`; also confirm you are signed in. |
| `503 bad_key` | The key is present but rejected by Anthropic. Revoke and reissue it, then `npm run ai:configure -- --replace`. |
| `429` / "assistant is busy" | Per-account rate limit or upstream limit. Wait and retry. |
| Answers look generic despite a live key | The app still grounds answers in retrieved topics when relevant; this is expected. |

The API key is never returned by any endpoint; `/api/ai/status` exposes only a
boolean and the model name.
